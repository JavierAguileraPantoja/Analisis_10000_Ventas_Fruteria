# Análisis de 10,000 Ventas - Frutería | Python + Pandas + IA
**Por Javier Aguilera Pantoja**

## El Problema
Una frutería vendía 5 productos pero no sabía cuál dejaba más dinero real después de la merma.

## Lo que hice
- Analicé 10,000 ventas con Python y Pandas en Google Colab
- Calculé dinero bruto, merma por producto y dinero neto
- Visualicé resultados con gráficas para tomar decisiones

## Resultados Clave
- Total vendido: $8,529,779
- Producto estrella: Mango con $3,812,025 (44.7% del total)
- Fresa: $1,628,700 | Plátano: $1,368,780 | Papaya: $1,082,424 | Naranja: $637,850
- La Papaya, con 40% de merma, deja la menor ganancia neta a pesar de vender mucho

## Recomendación
1. Priorizar inventario de Mango y Fresa
2. Reducir compra de Papaya, solo comprar lo que se vende
3. Crear promoción de jueves para producto maduro y bajar merma

## Stack
Python, Pandas, Matplotlib, Google Colab, SQL, IA Generativa
